# 実運用向け開発ロードマップ

命式自動計算の精度検証は後回しとし、日々の鑑定業務で使いやすくする改善を優先する。

## 優先度 高

1. 相談者一覧の改善
   - 登録日・更新日・最終鑑定日を確認しやすくする
   - 最近更新した相談者を上位表示
   - 検索性を維持する

2. 相談者削除UI
   - 既存の DELETE /api/clients/{client_id} を管理画面から利用できるようにする
   - 削除前に相談者名を表示して確認する
   - 出生情報・命式・鑑定履歴も連動削除されることを明示する

3. 鑑定履歴の編集・削除UI
   - 既存の PATCH /api/clients/{client_id}/readings/{reading_id} を利用
   - 既存の DELETE /api/clients/{client_id}/readings/{reading_id} を利用
   - 誤削除防止の確認を入れる

## 優先度 中

4. 相談者詳細画面の視認性改善
5. スマートフォン表示の改善
6. 鑑定書/PDF出力

## 後回し

- 算命学命式自動計算の複数ケース精度検証
